# mjoe-page
毛乔的个人主页

```bash
bun dev
```

Technical Stack:
- React Router
- motion/react
- shadcn/ui
- bun
- mdxjs

AI Agent was used during the development.

## Blog post status

In an MDX post's frontmatter, set `completed: false` to mark the post as unfinished. Set `completed: true` or omit the field for a completed post.

```yaml
---
title: "文章标题"
date: "2026-01-25"
category: "essay"
completed: false
---
```
